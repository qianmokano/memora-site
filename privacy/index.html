Memora 隐私政策

生效日期：2026 年 11 月 24 日

English

一、引言

Memora（以下简称「本应用」）是一款面向全国硕士研究生招生考试的复习应用。本政策说明本应用如何处理您的信息。使用本应用即表示您已阅读并理解本政策。

本应用的开发者（以下简称「我们」）不收集、不存储、也无法访问您的任何个人信息或使用数据。本应用不设账号体系，不展示广告，不包含任何分析、统计或跟踪工具，也不设有开发者自己的服务器。

您的信息仅可能存在于以下位置：您的设备；您选择的人工智能服务提供商；您主动开启的同步服务（iCloud 或 WebDAV）。

二、存储在设备上的信息

您在本应用中产生的对话、错题、题目图片、复习记录、学习计划、学习档案、人工智能记录的学习情况以及专注记录，均存储在您的设备上。

三、向人工智能服务提供商发送的信息

本应用不内置人工智能服务。您需要在「设置 → AI 服务」中自行配置服务提供商，例如 DeepSeek、通义千问、智谱、Kimi、OpenAI、Claude、Gemini，或您自行填写的其他服务地址。

当您使用提问、拍题、整理错题、批改、生成练习、复习推荐或学习报告等功能时，本应用会将完成该功能所需的以下信息发送至您配置的服务提供商：

  • 题目文字、题目图片及当前对话内容；
  • 与该功能相关的错题、学习档案（如报考科目、考试日期）及人工智能记录的学习情况。

上述请求使用您本人的 API Key，由您的设备直接发送至服务提供商，不经过我们的任何服务器。服务提供商对上述信息的处理，适用其各自的隐私政策。在您配置服务之前，本应用不会发送任何信息。

四、API Key

您的 API Key 存储在设备的钥匙串中。开启 iCloud 同步后，API Key 通过 iCloud 钥匙串在您的设备之间同步。

WebDAV 同步的数据包含 API Key。导出备份时，您可以选择使用密码加密 API Key（默认）、不加密，或不包含 API Key。请妥善保管您的同步账号和备份文件。

五、同步

同步功能默认关闭，您可以在「设置 → 同步」中开启：

  • iCloud：数据存储在您本人的 iCloud 私有空间中，仅登录同一 Apple 账户的设备可以访问，其保护方式适用 Apple 的相关政策。
  • WebDAV：数据通过 HTTPS 传输，存储在您指定的服务器上（例如坚果云或您自建的网络存储），其保护方式取决于该服务器。

我们无法访问上述任何一处的数据。

六、备份

备份文件由您在「设置 → 备份与恢复」中主动导出，存放于您选择的位置，并由您自行保管。备份中 API Key 的保护方式见第四条。

七、系统权限

本应用仅在您使用相应功能时申请以下权限，您可以随时在系统设置中关闭：

  • 相机（iPhone 和 iPad）：用于拍摄题目。
  • 照片：通过系统照片选择器选取图片，本应用仅能读取您选中的图片。
  • 文件（Mac）：您选择、拖入或粘贴的图片文件，本应用仅能读取这些文件。
  • 通知：用于复习提醒和专注提醒，通知由设备在本地生成。
  • 屏幕使用时间（iPhone 和 iPad）：用于强制专注功能，在专注期间限制您选定的应用。您的选择由系统保管，本应用仅获得无法识别具体应用的标识。

八、运行日志与崩溃报告

本应用会在设备上记录运行事件和崩溃报告，用于保障运行稳定。日志仅记录事件类型和数量，不包含题目、对话内容或 API Key，并仅保留最近 7 天。日志和崩溃报告保存在设备上，不会被上传。

如果您在系统设置中开启了「与 App 开发者共享」，或通过 TestFlight 参与测试，Apple 可能依据其政策向我们提供崩溃报告及您主动提交的反馈。

九、删除信息

  • 在 iPhone 和 iPad 上，删除本应用即删除存储在设备上的全部信息。在 Mac 上，将本应用移到废纸篓后，请同时删除「~/Library/Containers/com.thekanojyo.memora」文件夹。
  • iCloud 中的数据，可在「系统设置 → Apple 账户 → iCloud → 管理储存空间」中删除。
  • WebDAV 中的数据，可在您的服务器上删除。
  • 已发送至人工智能服务提供商的信息，依该服务提供商的规定处理。

十、未成年人

本应用面向准备研究生招生考试的用户，不面向 13 周岁以下的儿童。我们不会有意收集任何人的个人信息。

十一、政策更新

本应用处理信息的方式发生变化时，我们将更新本政策，并修改页首的生效日期。

十二、联系我们

如您对本政策有任何疑问，请发送电子邮件至 qianmokano@gmail.com。
