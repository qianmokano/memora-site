Memora 隐私政策

2026 年 11 月 20 日生效

English

概述

Memora 是一个考研复习 App。开发者不收集、不上传，也看不到你的任何数据。Memora 没有账号，没有广告，也没有分析或跟踪工具。

你的数据只会去三个地方：你的设备、你选择的 AI 服务商、你自己打开的同步（iCloud 或 WebDAV）。下面逐项说明。

保存在设备上的数据

对话、错题、题目图片、复习记录、学习计划、学习档案、AI 记住的学习情况和专注记录，都保存在你的设备上。

发送给 AI 服务商的内容

Memora 不自带 AI。你在「设置 → AI 服务」里连接自己的服务商账号，比如 DeepSeek、通义千问、智谱、Kimi、OpenAI、Claude、Gemini，或你填写的其他地址。

提问、拍题、整理错题、批改、生成练习、复习推荐和学习报告时，App 会把完成这件事需要的内容直接发给这个服务商：

  • 题目文字和图片，以及当前对话；
  • 和回答有关的错题、学习档案（如科目、考试日期）和 AI 记住的学习情况。

这些请求用你自己的 API Key，从你的设备直接发出，不经过开发者的服务器。服务商如何处理这些内容，以它自己的隐私政策为准。没有连接 AI 服务时，不会发送任何内容。

API Key

API Key 保存在设备的钥匙串里。打开 iCloud 同步时，它通过 iCloud 钥匙串在你的设备之间同步。

导出的备份文件和 WebDAV 同步里也包含 API Key，这两者都没有加密，请自己保管好。

同步

同步默认关闭，在「设置 → 同步」里打开。

  • iCloud：数据存在你自己的 iCloud 私有空间，只有登录同一个 Apple 账户的设备能读取。
  • WebDAV：数据存在你填写的服务器上，比如坚果云或你自己的 NAS。

开发者都无法访问这些数据。

备份

备份文件由你在「设置 → 备份」里导出，存放在你选择的位置，由你自己保管。备份文件没有加密。

权限

  • 相机：拍摄题目。
  • 照片：通过系统的照片选择器，App 只能读到你选中的那几张。
  • 通知：复习提醒和专注提醒，由设备本地生成。
  • 屏幕使用时间：用于强制专注，在专注期间屏蔽你选的 App。你选了哪些 App 由系统保管，Memora 只拿到无法识别的标识，看不到具体是哪些 App。

日志和崩溃报告

App 会在设备上记录运行事件和崩溃报告，用来排查问题。日志只记发生了什么和数量，不记题目、对话和 API Key，保留最近 7 天。

它们不会自动上传。只有你在「设置 → 开发者 → 日志」里手动导出并发送给开发者时，才会离开设备。如果你在系统设置里打开了「与 App 开发者共享」，Apple 会按它的政策把崩溃数据转交给开发者。

删除数据

  • 删除 App，会删掉设备上的全部数据。
  • iCloud 里的数据，在「系统设置 → Apple 账户 → iCloud → 管理储存空间」里删除。
  • WebDAV 里的数据，在你的服务器上删除。
  • 发给 AI 服务商的内容，按该服务商的方式处理。

未成年人

Memora 面向备考研究生考试的用户，不面向 13 岁以下的儿童，也不会有意收集任何人的个人信息。

政策变更

App 处理数据的方式有变化时，会更新这份政策和顶部的生效日期。
